# 换电脑安装与数据同步

## 已同步的内容

- 全部受版本管理的源码、需求、设计说明、测试和打包脚本。
- `dist/`：可直接使用的 AutoCAD 2018–2024、2025 安装包及运行依赖。
- `bin/`：本地保留的历史安装包和 Update 系列文件，供回溯使用。
- `artifacts/`：四个 CAD 编译版本的现有输出。
- `userdata/BomCadPlugin/component-rules.json`：从 `%APPDATA%\BomCadPlugin\component-rules.json` 原样复制的完整规则库。

2026-10-19 快照：默认体系 3 条规则、2 个体系参数；钢框体系 23 条规则、3 个体系参数。保留全部构件名称、图块名称、构件引用代号、公式、单位、分组、备注、参数定义和默认值。顶层 `rules` 与 `productSystems` 均完整保留。

`obj/`、源码目录下的重复编译缓存、IDE 临时文件不参与同步。Autodesk 宿主 DLL 由目标电脑上的 AutoCAD 提供，不能用仓库代替安装 AutoCAD。

## 在另一台电脑安装

1. 安装 Windows 版 AutoCAD 2018–2025。2018–2024 需要 .NET Framework 4.8；2025 使用 AutoCAD 自带的 .NET 8 环境。不支持 AutoCAD LT。
2. 克隆仓库，或使用 GitHub 的 Code → Download ZIP，解压整个目录。
3. 关闭 AutoCAD，双击 `Install.cmd`，输入 AutoCAD 年份。例如输入 `2025`。
4. 安装程序将匹配的 bundle 放到 `%APPDATA%\Autodesk\ApplicationPlugins\`，将规则放到 `%APPDATA%\BomCadPlugin\component-rules.json`，并校验复制文件的 SHA-256。
5. 打开 AutoCAD，打开并保存 DWG。执行 `BOM_RULES`，应看到默认体系和钢框体系。执行 `BOM_PARAMS` 选择体系、设置层高和墙厚等项目参数，然后执行 `BOM_STAT`。

也可以在仓库根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Local.ps1 -AutoCADVersion 2025
```

重复安装会恢复仓库中的规则快照，并将原有规则和当前用户的旧 BOM 插件保存在 `%APPDATA%\BomCadPlugin\backups\时间-唯一编号\`。如果新电脑已有要保留的新规则，请先导出并同步它们再安装。

如果 `C:\ProgramData\Autodesk\ApplicationPlugins\` 中已经有旧的 BOM 插件，安装程序会在修改文件前停止并显示路径。先关闭 CAD，将该旧 bundle 备份并移到 ApplicationPlugins 目录之外，再安装，避免两份插件同时加载。

## 图纸和项目参数

本次 BOMlist 项目目录没有 DWG、DXF 或 `.bomconfig.json` 文件。规则库中的“图块名称”只是匹配规则，不包含图块的几何定义。

要继续统计已有项目，请把原 DWG 和它同目录、同名的 `.bomconfig.json` 一起复制到另一台电脑，并保持二者在同一目录。这个文件保存项目名称、所选体系、层高、模板高度、墙厚和项目自定义参数。没有旧配置时，通过 `BOM_PARAMS` 为图纸重新设置即可。

## 以后继续同步规则

插件运行时仍将规则保存到用户目录；它不会自动修改 GitHub。修改体系、构件或规则后，关闭 CAD，在仓库根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Export-UserData.ps1
git add userdata/BomCadPlugin/component-rules.json
git commit -m "data: update BOM product systems and component rules"
git push origin master
```

另一台电脑执行 `git pull`，关闭 CAD 后重新运行安装程序，即可恢复更新后的规则。两台电脑应轮流同步，避免把尚未导出的修改覆盖掉。
